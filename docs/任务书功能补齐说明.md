## 用饵量为什么分两套口径

第一版只做了养殖投喂（亩产 × 面积 × 饵料系数），一跑就发现不对：这家的产品是 200g 小包装钓饵，5 亩塘算出 45000 包。
所以拆成两套，由参数决定：

- **养殖投喂**（传 `area_mu`）：总需饵 = 亩产(kg/亩) × 面积 × 饵料系数(FCR)，再折算成包/箱/吨。
- **作钓用量**（传 `trips`，不传面积）：总包数 = 次数 × 人数 × 2 包（常见区间 1~3 包/人次）。

两个都不传时按 1 次作钓算 —— 这家客人多数是钓友，按 1 亩养殖算会得出几千包这种明显不成立的数字。

鱼种参数表（亩产 / FCR / 周期 / 日投饵率）在 `agent/feeding.py` 的 `FEEDING_PROFILES`，
取值是池塘主养的常规参考值，输出时会明确写出计算口径，便于按实际情况折算。

## 答辩怎么演示

1. **引导下单**：对话框问「红虫颗粒怎么下单」→ 出「下一步：在线下单」卡 → 点「去下单」→ 下单页已预选该商品。
2. **用量测算**：问「5 亩塘养鲤鱼要备多少饵」（出养殖口径）与「周末去黑坑买多少」（出作钓口径），两次对比能看出是两套算法。
3. **备货状态**：下单 → 支付 → 个人中心订单状态显示「备货中」；后台发货后变「已发货」。
4. **缺货提示**：后台 `/admin/dashboard/` 顶部「待处理提醒」+「缺货与库存预警」表；登录后台直接落这个页面。
5. **凭手机号查单**：退出登录 → 查订单页填手机号 + 订单后四位 → 查到那一笔；只填手机号会被要求补订单号。
